## 1. 背景与目标

「奶龙大学」是 2026 年 10 月起的中文互联网整活现象：把「奶龙」形象与真实高校结合，做成跳转页或完整的虚构大学官网。现有参考包括中国奶龙大学、国立河南奶龙大学、大连奶龙大学等。

本项目为北京建筑大学（北建大）做一个非官方趣味二创单页站「北建奶龙大学」，目标是：

1. 第一眼像真实高校官网：建大紫、建筑校园影像、正式栏目与排版。
2. 第二眼发现奶龙：巨型奶龙雕塑、奶龙化新闻与学院文案、入学纪念卡。
3. 保持可核查：真实校史、校训、校区、学科事实不变，虚构内容明确标注。
4. 纯静态、零构建、可直接部署到 GitHub Pages。

## 2. 非目标

- 不做真实招生、缴费、学籍、学位或任何办事功能。
- 不冒充北京建筑大学官方；不复制真实校徽、真实人物照片或受版权保护的奶龙官方素材。
- 不引入框架、构建步骤、后端、数据库、Cookie 或第三方统计。
- 不做多页官网；新闻详情、学院详情、校园导览均在单页内以锚点或弹窗呈现。

## 3. 定位与受众

- 定位：一所「认真做建筑、顺便很可爱」的虚构大学官网。
- 受众：北建大学生、校友、建筑类院校学生、奶龙爱好者、被分享链接吸引的访客。
- 语气：官方措辞为骨架，奶龙梗只出现在标题、简介和活动文案里；不玩低俗梗，不使用真实师生姓名。

## 4. 设计原则

1. **像真优先**：版式、导航、信息密度先对齐真实高校官网，奶龙是彩蛋不是主色。
2. **紫色定调**：建大紫承担品牌识别，奶龙黄只做强调与状态。
3. **事实可查**：真实数据集中在「学校概况」；虚构内容在文案或脚注中标注「趣味设定」。
4. **克制动效**：只保留淡入、悬停和弹窗过渡，尊重 `prefers-reduced-motion`。
5. **单文件可维护**：内容直接写在 HTML，交互集中在 `app.js`。

## 8. 交互规格

### 8.1 新闻筛选

- 按钮：全部 / 校园动态 / 学术脑洞 / 生活灵感。
- 每个新闻卡带 `data-category`。
- 选中按钮设置 `aria-pressed="true"`；其余为 `false`。
- 切换时只隐藏不匹配卡片，不做动画或仅做 150ms 淡入。
- 结果数量通过 `aria-live="polite"` 播报。

### 8.2 校园导览弹窗

- 使用原生 `<dialog>`，每个地标一个。
- 打开时 `showModal()`；关闭按钮、Esc、点击遮罩均可关闭。
- 关闭后焦点返回触发按钮。
- 弹窗内含图片、标题、2–3 句介绍、标签。

### 8.3 入学纪念卡

- 表单字段：昵称（必填，≤12 字）、学院（下拉，6 个重点学院）。
- 生成 1000×630 的 SVG 纪念卡：
  - 深紫底 + 细线边框 + 校徽 + 「入学纪念卡」标题。
  - 昵称、学院、日期（本地日期）。
  - 卡号 `BNLU-YYMMDD-XXXX`，后四位由 `crypto.getRandomValues` 生成。
  - 底部固定文案「非录取凭证 · 仅供娱乐纪念」。
- 昵称在写入 SVG 前做 XML 转义。
- 下载通过 `Blob` + `URL.createObjectURL` 导出 `.svg`。
- 不写 `localStorage`，不发网络请求。

### 8.4 其他

- 移动端（≤860px）汉堡菜单，按钮维护 `aria-expanded`，打开后锁定滚动。
- 滚动超过 600px 显示「回到顶部」。
- 锚点跳转使用 `scroll-behavior: smooth`；`prefers-reduced-motion` 时关闭。
- 导航当前项用 `IntersectionObserver` 高亮，失败时不影响使用。
- 全站键盘可操作，焦点样式清晰。

## 9. 技术架构

```
北建奶龙大学/
├── index.html          # 全部静态内容与语义结构
├── styles.css          # 设计令牌、布局、组件、响应式、打印
├── app.js              # 导航、筛选、弹窗、纪念卡 UI、回到顶部
└── assets/
    ├── card.js         # 纯函数：昵称校验、XML 转义、卡号、SVG 生成
    ├── seal.svg        # 自绘校徽 / favicon
    └── images/         # Seedream 生成的 7 张图片
```

开发期辅助文件（不属于线上站点）：

- `tests/card.test.cjs`：`card.js` 的 Node 内置测试。
- `scripts/check-site.mjs`：静态站点结构自检脚本。

- 纯 HTML + CSS + 原生 JS，无框架、无构建、无依赖。
- 内容静态写入 HTML，便于 SEO 与无 JS 时阅读；JS 只负责交互。
- 脚本以 `defer` 加载，使用 IIFE 避免全局污染。
- 不使用外部字体、CDN、统计脚本、Cookie、`localStorage`。
- 图片使用本地文件，配置 `loading="lazy"`（Hero 除外）与固定宽高。
